***OOPs is life***

- Programming is used to solve real-world problems, OOPs helps us to model real-world systems with programming languages.
- OOPs is a programming style, that involves dividing a program into pieces of objects that can communicate with each other.
- OOPs is an object based coding style, in which each object has its own attributes and behaviour.
- Fundamental idea is to combine into single unit, both data and behaviour, that will promote modularity.
- OOP promotes modularity by encapsulating data and behaviour with objects. This modular approach enhances code reusability and maintainability, as objects can be reused in different parts of the program.
