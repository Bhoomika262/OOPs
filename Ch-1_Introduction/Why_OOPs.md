# Functional Programming
- Functions are used
- There are several limitations in functional programming
- Example: Our code needs 100 students. And all the students have different properties. In functional programming, we have to make different functions for each student because of their unique properties(age, name, roll no.,etc.).

# Drawbacks of functional programming
1. Doesn't model real world problem very well(like the student example).
2. If a new data is added, all functions need to be modified.(for eg: if we have a new property of student like number of subjects, we will have to modify all the functions of each student).
3. Global data is accessible to all the functions.(If we have to hide some data from any function, its not possible in functional programming.)
4. No clear boundaries and well definition of code.
5. No modularity. Functional programs can become monolithic and difficult to maintain as they grow in complexity.
